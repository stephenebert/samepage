Fresh SamePage held-out bilingual hobby-policy corpus

This subtask read only production lib/studio-engine.ts, lib/studio-types.ts,
and lib/studio.ts to learn the grammar. It did not read previous evaluation
corpora or model outputs. All policy texts, expected rules, concrete outcomes,
and direct oracle formulas were authored before any live provider request.

Files
  sources.json: policy source texts only; no expected answers.
  goldens.json: independent expected rules, outcomes, discovery, and journey.
  corpus.json: combined sources and goldens; never send this whole file to a model.
  author-corpus.py: deterministic authoring script with explicit outcome tuples.
  verify-corpus.py: standalone direct semantic oracle and separate AST interpreter.
  truth-verification.json: successful offline verification report.
  freeze.json: SHA-256 hashes fixed before live evaluation.

Runner contract
  Join sources and goldens by id. Preserve source text exactly. Only source
  text fields may enter the production job prompt. Golden AST structure and
  labels are one valid encoding, not an exact-shape requirement for a model.
  Judge returned rules semantically, including all supplied concrete scenarios.
  Discovery witness IDs and price delta maxima are exact-set expectations;
  individual witness attendee selections and checked-case counts may depend on
  an interpreter's equivalent AST shape. Only unresolved checkedCases is fixed.
  The fourth stage must produce rules:null and nonempty clarification issues
  for both candidates. It must not partially compile even on easy attendees.

Ordered stages
  1. lantern-nested-utc: differing only at the exact closing UTC instant.
     Youth exclusion has a resident-AND-scholarship exception scoped to consent.
  2. mosaic-priority: same admission but two directions of fee difference.
     Alice scholarship is fourth; Bob scholarship is first. Max price deltas
     are 1600 cents (Alice higher) and 500 cents (Bob higher).
  3. mosaic-corrected: edit Alice only in the mosaic room; Bob source unchanged.
     Both candidates are equivalent after correction. Explicit journey moves
     an identical attendee from an old Alice $16 receipt to a new free receipt.
  4. watercolor-overlap: both sources have conflicting whole prices with no
     priority. Both complete interpretations must remain unresolved.

Verification
  Run python3 verify-corpus.py. It imports no production code and makes no
  API/browser/network calls. It checks 118 authored executable decisions and
  eight required abstentions. It compares the golden ASTs with direct boolean
  and fee formulas over all 121 integer ages, 32 flag combinations, and every
  relevant UTC truth region represented by boundary, adjacent, distant, and
  intervening sample instants: 178112 candidate decision comparisons.
  This verifies synthetic expected semantics, not live model faithfulness or
  translation quality. A separate runner and human-language audit are needed
  to assess those aspects. Do not adapt expected values after seeing outputs.
